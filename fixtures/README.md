# Fixtures

Real glyph outlines used by tests, stored as JSON in the core's own `Path` format.
Only use outlines from fonts whose licence allows it (e.g. SIL Open Font License), and note the source font and licence next to each file.

- `source-serif-4.json`: six glyphs (a, e, g, o, B, R) from Source Serif 4 Regular, SIL Open Font License 1.1, taken from `@fontsource/source-serif-4`. Outlines are SVG path data in font units (y up).
